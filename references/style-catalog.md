# Lany Avatar 风格目录

只有需要选择、切换或比较风格时才读本文件。默认精修当前媒介，不需要逐张加载全部示例。

## 使用优先级

1. 用户明确指定的身份与具体修改要求优先。
2. 风格名、下列编号或 ID 选择一项。单次只选一个媒介；明确要求多版时各自独立生成，不拼成风格混合。
3. 用户自定义的新风格不必强行归入目录，仍保留身份与单版默认。
4. 媒介样例不是新的身份基准，也不固定其动作、表情或构图；脸和配饰优先沿用本轮目标。
5. 无特殊配色要求时采用下列背景；只精修现图或明确说不换背景时保留原背景。纯色铺满方图，不预画圆框。

## 身份参考与文件选择

- 默认身份源为 [像素参考](../assets/lany-avatar-reference.png)。自然手绘分支可用 [手绘参考](../assets/lany-avatar-handdrawn-reference.png)。本轮用户指定的图优先。
- 将身份图与本节对应的媒介样例分别标注用途后送给图像工具；不要把参考图数量理解为输出数量。
- 只有所选风格需要时才查看相应图片。以下样例路径均可随技能目录迁移，不依赖本机生成历史。
- 全身样例不意味着每次都输出全身：用户要头像时头肩构图；要全身小人、玩偶或建档确认图时再用对应全身结构。

## pixel

编号 01；中文名：像素；状态：当前默认身份参考。

参考：[样例](../assets/lany-avatar-reference.png)。默认背景：满版主题黄绿。

保持可见方形像素、统一像素尺度和阶梯轮廓；黑发和黑衣用少量炭灰色块分层，面部避免平滑滤镜。精细像素仍属于本风格，不因导出尺寸变大就声称细节提升。

可直接调用：使用 $lany-avatar，风格 pixel，保留当前角色和主题色，精修镜框、耳机与发束，只生成一张头像。

补充参考：[精细像素补充试样](../assets/styles/pixel-fine.png)。

## soft-handdrawn

编号 02；中文名：自然手绘；状态：可选内置参考，非默认。

参考：[样例](../assets/lany-avatar-handdrawn-reference.png)。默认背景：满版雾蓝灰。

使用自然黑墨线、轻纸纹、克制色块和一两层阴影；保留年龄感与原脸型。默认满版雾蓝灰，不恢复米白外角、黑边或两色圆底。可借用 lany-handdrawn-ip 的画法，但当前身份与背景以本目录为准。

可直接调用：使用 $lany-avatar，风格 soft-handdrawn，自然墨线、雾蓝灰满版背景，不加腮红，只生成一张头像。

## cel-anime

可直接调用：使用 $lany-avatar，风格 cel-anime，清楚线条和两级色块阴影，自然闭口浅笑，只生成一张头像。

## storybook-3d

编号 06；中文名：温暖动画 3D / Q版；状态：头像与全身均为待确认试样。

## 共同限制

- 身份与媒介分开：不换脸，不移植其他创作者的独特外貌、标志或固定场景。
- 不把只请求示例预览、说明文档或风格规划的任务变成生图任务。
- 用户要求文档整合，不代表同意采用候选、替换默认头像、改账号或批量修改其他技能。
- 实际生成后检查主体、材质、背景和构图；头像额外检查圆裁。完整提示词与本次参考关系保存在任务输出目录。
- 记录实际原图尺寸。当前打包样例为 1254×1254，不宣称为原生 2K 或 4K。
- 正式漫画建档仍遵守 comic-ip-onboarder 的独立审美确认步骤；此目录不提供已确认三视图或表情包。
