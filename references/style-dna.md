# Lany 小生 · Style DNA

## 默认身份与媒介

- 默认媒介：自然手绘 `soft-handdrawn`。默认身份参考是 [原自然手绘头像](../assets/lany-avatar-handdrawn-reference.png)，本轮用户指定或确认的身份图始终优先。
- [像素兼容参考](../assets/lany-avatar-reference.png) 只在明确选择像素时使用，两者是同一个 Lany。像素不是默认，也不因参考图数量增加输出。
- [风格目录](style-catalog.md) 和 `assets/upperbody/` 提供媒介样例。2026-10-26 的四张上半身图仍是未选定候选，不替换上述身份图，不固定样例中的穿搭或表情。

## 身份不变量与可选穿戴

保留年轻自然窄脸、原有五官关系、黑色蓬松短发、自然中性浅米肤色和专注亲和的气质。媒介转换可简化笔触或材质，但不能重塑成陌生人的脸。

- 墨镜／护目镜、耳机、黑卫衣和蓝色小标记都不是身体特征，不要求每张都有。头像默认不拿电脑或其他物品；按场景可选择更休闲的穿搭。
- 局部编辑保留未要求修改的穿戴；换装或移除配饰时自然补全发束、颈部、衣领，不留下镜框形空洞或悬浮零件。
- 视线明确、眉形自然、闭口浅笑克制。避免空洞圆睁眼、夸张歪嘴、巨大高光、腮红、橙红肤色、磨皮或美颜式尖下巴。
- 只在实际佩戴时核对镜框、耳罩、铰链与衣领交叠；精修不等于堆配饰和反光。

## 头像构图与配色

- 默认正方形、完整头顶、颈肩至胸口，身体自然延伸到下边缘；不把头像变成全身小人或放在底座上的雕像。
- 让脸、眼睛和下巴处于圆裁安全区，检查 48px／96px 识别。留白根据实际发型调整，不把未经验证的百分比当成精确承诺。
- 自然手绘默认雾蓝灰 `#DDE3E5` 满版；像素和多数可选媒介默认主题黄绿 `#D8FF00`；简约扁平漫画默认暖米白 `#F6F3EB`。用户指定色优先，主题色不得污染肤色。
- 不预画黑色外圈、两色角或圆底，圆形仅作裁切预览。头像不加入口号、名称或场景文字。

## 候选与默认的边界

普通生成和 README 画廊更新不表示选定默认头像。明确要求更新身份资源时，备份后只替换指定资源并记录用途；不自动改账号、发布内容或同步其他技能。更多媒介处理按 [风格目录](style-catalog.md)。
